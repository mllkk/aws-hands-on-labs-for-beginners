# ☁️ AWS Beginner-Friendly Hands-On Labs

Welcome to my AWS Learning Repository! 🚀

This repository is a collection of beginner-friendly, hands-on labs and practical cloud architecture exercises designed to explore and learn core Amazon Web Services (AWS) concepts from the ground up. 

Each directory inside this repository represents an independent, end-to-end lab exercise. All labs are based on hands-on tutorials and community resources found across the internet. You can find direct links to the original sources within each lab's respective `README.md` file.

---

### 🎯 Purpose & Goals

* **Hands-on Experience:** Moving beyond theory by building real-world cloud architectures.
* **Core Service Understanding:** Getting familiar with foundational AWS services including compute, serverless, databases, APIs, and security.
* **Continuous Learning Log:** Documenting my cloud journey and creating a reusable reference guide for cloud enthusiasts.
